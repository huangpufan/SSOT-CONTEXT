## Revised mechanism and acceptance

The adopted proposal returns to the 5.2 capture text and changes only the existing readback step: corrections also compare with the pre-edit owner's necessary source excerpts. Their wording remains within current retention authority, and the superseded scope is marked. This supplies a second comparison input to the existing verification, rather than prescribing a quotation layout, a transcript or a separate archive. It does not change write permission or reopen formal accepted decisions when their original exchange is unavailable.

Acceptance requires preserved necessary source words and scoped replacement, correct fresh-consumer output, unchanged independent boundaries, excluded diagnostic details and honest persistence/implementation claims. Source retention must also respect a later authorized redaction. The observed failure occurred during mutation and escaped readback; interpreting “the source” as only the latest exchange is a plausible hypothesis, not an established model mechanism.
