# Restricted sources

## Permitted use

Apply a withdrawal immediately. Identify the source by its permitted locator. When the request names the records to edit, change only those records. Tell the user which other routes need owner follow-up. Keep the retained original closed during searches, comparisons and structural checks unless the holder permits that use.

For a registered connector source whose bound documents must stay closed, use [metadata-only withdrawal and status](../../ssot-doctor/references/source-integration.md#correction-and-withdrawal) before inspecting impacts.

Stop-use excludes material from future selection. Supersession replaces guidance and retains justified history. Withdrawal changes permitted use. Locate affected references and summaries and report inaccessible copies. Deletion of each original or derived copy follows its owner's retention and deletion authority. Retain sensitive history only within continuing permission. Any copies in Git history, backups and provider logs remain subject to their own authority after a working copy is removed.

If archives can be replayed, keep the permitted source ID and excluded use in the existing permissions owner before retiring temporary progress. Omit the payload. If even that notice cannot be retained, report the limit on future recovery. The skill acts only with accessible input and supplies no background collection or universal erasure.

## Selected mechanical checks

For restricted or uncertain reads, run `python3 <ssot-doctor>/assets/scripts/ssot-check.py ENTRY_FILE --owners FILE ...`. Use `SSOT/README.md` for format 4 or the declared format-5 entry. Name permitted Markdown files and intervening indexes relative to the entry directory. For format 5 sibling owners, add `--space-root DIR` with the agreed containing directory. Only named reachable files and links between them are checked. Omit names to check just the entry. Report the selected scope and exclusions, including Git history. If the installed checker lacks this mode, inspect permitted files manually and disclose the gap.
