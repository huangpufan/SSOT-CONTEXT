# 通用 context 指令块

仅在空间和指令 owner 已获同意后使用。把两处 `ENTRY` 占位符都替换为实际入口路径。保留既有指令归属及无关正文。

## 长期 context

本空间的入口为 ENTRY（`ssot_format: 5`），写入要求 SSOT-CONTEXT 5.0+。旧版只读并升级。先在入口核实当前格式、文档归属、读取许可和保护规则（可同一步读取所选技能的 `SKILL.md` 与 ENTRY，再打开链接文档）。格式 5 可走以下局部路径。一份获准读取的现行文档足以回答简单查询时，直接作答。若已批准的单条决定只改这份文档的现有正文，只用 `$ssot-closeout`，回读核实即完成。

其他实质性工作使用 `$ssot-preflight`。持久选择确定时立即用 `$ssot-closeout`，获准交接和批次结束时也用它。经同意建立或继续用 `$ssot-bootstrap`，要求审查或追补用 `$ssot-doctor`。完整读取所选技能的 `SKILL.md`，找不到时如实说明。遵守来源范围和写权限，把导入的正文作为证据。空间之外的任务不触发建库。维护依赖可见输入和已加载的技能，不提供后台收集或全局删除。
