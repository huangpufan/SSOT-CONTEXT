# 委托子 Agent 跳过条款为何保留 5.16、不发布 5.17

**2026-11-24，经过 12 组配对（24 个原生 Codex 会话）冻结对照试验后，决定保留协议 5.16，不发布“委托子 Agent 跳过预检/收尾”候选 5.17。** [Stage 5 真实会话审计](2026-11-24-real-session-stage5-audit.md)发现 211 个 Codex 子 Agent 线程占全部真实消费输入的 52.6%，且 91% 重跑了预检。本轮在双语受管指令块（`adapter-thin.md`、`context-adapter.md`，严守新建的 1,600 字节硬帽）与 `ssot-preflight/SKILL.md`、`ssot-closeout/SKILL.md` 中新增委托子 Agent 跳过条款：仅当父级给清范围、权限/保护边界且声明父级负责收尾时跳过重复预检与收尾。实测在 Codex CLI `0.171.0`（`gpt-6.1-terra`，`medium`）上，24/24 会话均通过行为质量核验，但 **6 组主委托场景上 5.16 基线本身已 6/6 跳过冗余协议读取（`proto=[]`）**，候选版反使主组输入微升 **+7.46%**（`269,620 → 289,745`，往返 `17 → 18`），顶层对照上升 **+25.41%**（`235,354 → 295,146`），并在编辑空间文档的受限反例上诱发了跳过 `ssot-closeout` 与 `source-retention.md` 的边界弱化，明确未达预设上线门槛。[冻结计划、逐次原生回执与脱敏归档哈希](../tests/benchmark/results/delegated-subagent-study.json)

## 机制结论：真正制造 Stage 5 子 Agent 税的不是 5.16 缺少跳过条款

1. **当父协调者明确给出范围、保护边界与收尾归属时，`5.16` 已经零冗余地工作。** 在 A 组全部 6 次基线会话中（覆盖 80–90 条不变量表、中英文编码、只读审查与格式 5 调研），现行 `5.16` 全部以 `proto=[]` 直接在 2–4 轮完成且 100% 通过质量核验。这意味着往每份 `AGENTS.md` 永久加 170–190 字节的委托跳过条款，对“写清简报的父子协作”没有任何额外省钱效果。
2. **在适配器里加入“可跳过预检/收尾”条款会制造真实的边界滑坡。** 尽管候选明确写了“改动空间文档不得跳过”，`sub_restricted_leak` 中候选版在修改格式 5 空间文档 `programme.md` 时依然跳过了 `ssot-closeout/SKILL.md` 与 `source-retention.md`（基线 `5.16` 两者均正常加载）。在多文档或复杂撤权条件下，这种跳过极易丢掉唯一历史理由或撤权检查。
3. **这直接修正了 Stage 5 审计中 91% 子 Agent 预检税的归因与下一步重心。** 真实生产中 192/211 子 Agent 重跑预检，主要来自三个与协议跳过条款无关的现实因素：(a) 此前 5 个活跃消费空间 100% 停留在 `5.5` 之前的旧指令块（本轮已全部升级并同步到 `5.16`）；(b) 现实中的父协调者经常直接抛出开放式子任务，未写清保护边界与收尾归属（此时子 Agent 本就不该跳过预检，如 `sub_unbriefed_protected` 所示）；(c) 当未获完整简报的子 Agent 或顶层会话确实需要做预检时，成熟仓库 251 KB / 366 条不变量的巨型 `SSOT/README.md` 导致了 1,351 次截断。因此，下一轮高杠杆方向转向 **P2（超长不变量表分片与按主题索引）**，并在已同步 `5.16` 指令块的真实空间上观察下一阶段会话分布。

## 观测口径披露与总量账目

按[评测方法](../tests/benchmark/METHOD.md)诚实披露两项本轮脚本观测缺口（均未篡改或重跑原始回执）：一是实时汇总脚本误读了不存在的 `final_answer` 键，最终裁决已全部直接核对各次冻结 `1.native.jsonl` 的原生助手消息；二是内核 `inotify` 窗口包住了 `transport.execute_turn()` 内部的前后工作树快照，使基线与候选在 `sub_format5_research` 和 `sub_restricted_leak` 上均记入 4 次相同的框架快照打开——原生命令流已逐条核对确认全部 24 个会话对 `vault/interview.md` 零引用、零打开且零密文泄漏，但“纯内核级独占零打开”仍在本研究中列为观测缺口。

24 个完成会话（Codex CLI `0.171.0`，实际返回模型均为 `gpt-6.1-terra`，推理档位 `medium`）合计消耗 **1,746,161** 输入（缓存 1,527,936、未缓存 218,225）、15,795 输出、96 次 API 往返、72 次工具调用、耗时 1,163.0 秒。完整冻结现场与原生日志（剔除 `codex-home`、`probes`、`auth.json`、`__pycache__` 与 `.git`）保存在本机私有归档 `delegated-subagent-10e2a6b-20261124.tar.gz`，SHA-256 记于[结果文件](../tests/benchmark/results/delegated-subagent-study.json)。
